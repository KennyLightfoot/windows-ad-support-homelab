# 30-Day Support Practice Plan

The infrastructure baseline is complete. Use three 60-90 minute sessions per week; school remains the priority.

## Week 1: Routine identity and access

- Complete a new-user onboarding ticket using the Users and Groups OUs.
- Reset a password and unlock a simulated account.
- Document the approved access request for `\\LAB-DC01\Helpdesk`.
- Complete one offboarding record and move the disabled user to Disabled Objects.

Evidence: four closed tickets, onboarding/offboarding checklists, one access-validation screenshot.

## Week 2: Endpoint support

- Verify `LAB-PC01` asset details and domain membership.
- Test Group Policy refresh and document expected login-notice behavior.
- Perform one Windows update/restart check and document validation.
- Practice a controlled standard-user versus administrator elevation request.

Evidence: three closed tickets, one asset update, one change record.

## Week 3: Troubleshooting

Work through scenarios 01-06. Use the troubleshooting worksheet before recording the cause. Change only one variable, verify the fix, then restore the baseline.

Evidence: six closed tickets with symptoms, tests, root cause, resolution, and verification.

## Week 4: Fractional operations

- Review backup status for both Windows VMs.
- Complete scenarios 07-10 that apply to the current environment.
- Write one incident report and one mock monthly client report.
- Review the repository for accuracy, secrets, and completed evidence.

Evidence: final sanitized repository, incident report, monthly report, and updated README summary.

## Definition of done

- [ ] 15 or more tickets are complete.
- [ ] Every ticket contains evidence and verification.
- [ ] Three changes contain risk and rollback sections.
- [ ] Onboarding and offboarding are complete.
- [ ] At least one restore or rollback is tested.
- [ ] Documentation matches the final lab.
- [ ] No secrets, real customer data, or public administrative endpoints exist.
