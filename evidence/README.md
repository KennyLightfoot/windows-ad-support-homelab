# Sanitized Evidence Guide

Evidence is intentionally documented but not committed yet. Add only screenshots that support a completed lab claim and that contain no credentials, private addresses, device serial numbers, or unrelated personal information.

| Filename | What it demonstrates |
|---|---|
| `ad-domain-validation.png` | `lab.home.arpa`, `LAB`, and AD DS/DNS service validation |
| `domain-join-validation.png` | `LAB-PC01` joined to the domain |
| `smb-access-denied.png` | Negative access test for a non-Helpdesk user |
| `gpo-login-notice.png` | Workstation GPO applied successfully |
| `proxmox-backup-success.png` | Successful final backup task to `pve-backup` |

Before committing a screenshot, check for passwords, email addresses, external IP addresses, browser tabs, personal files, and host identifiers. Crop to the relevant result where possible and use fictional users only.
