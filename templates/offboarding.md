# Employee Offboarding Checklist

- [ ] Authorized request and effective time confirmed.
- [ ] Account disabled at approved time.
- [ ] Active sessions revoked where supported.
- [ ] Group and application access removed.
- [ ] Shared credentials rotated if exposure was possible.
- [ ] Device and accessories recovered/recorded.
- [ ] Business data transferred to approved owner.
- [ ] Email/file retention action documented where applicable.
- [ ] Remote access, VPN, tokens, and keys removed.
- [ ] Manager confirms completion.
- [ ] Ticket, inventory, and documentation updated.
