# Employee Onboarding Checklist

- [ ] Authorized request received from approved manager.
- [ ] Start date, role, manager, and required access confirmed.
- [ ] Standard user account created.
- [ ] Correct groups assigned using least privilege.
- [ ] Administrative access excluded unless separately approved.
- [ ] Device assigned and recorded.
- [ ] Updates and approved software installed.
- [ ] MFA/security enrollment simulated or completed where supported.
- [ ] Shared folders and applications tested.
- [ ] Printing tested if required.
- [ ] Temporary credential handled securely; not recorded in repository.
- [ ] User/manager confirms successful access.
- [ ] Ticket and asset inventory updated.
